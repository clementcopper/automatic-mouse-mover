## Decisions
- Swift port (v2.0) instead of patching Go: ~40 % of the Go code was runtime bridging and every recent bug lived there. Branch `swift-port`; Go stays reachable as tag `v1.6.1`.
- Tests are a plain executable (`swift run amm-tests`), no framework — the CLT ship none and the engine is synchronous.
- Everything on the main thread. The wake handler only checks; the restart branch and `wantRunning` are gone.
- Cadence documented as 60–90 s rather than "fixed".
- Version lives in `Info.plist` only; the app reads it from the bundle.
- The tray icon is loaded from `Contents/Resources` at launch, not embedded, and not flattened (19 s / 4 d measured with the vector image).
